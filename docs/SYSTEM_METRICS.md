# Understanding System Metrics

SysTuklas displays system information to help you investigate performance. A single high reading does not automatically mean a computer has a fault.

## CPU usage

Short spikes are normal when applications start, compile code, or load data. Look for sustained high usage alongside slow response times, and identify which process is responsible before closing anything.

## Memory (RAM)

High RAM use can be normal because operating systems use available memory for applications and caching. Check available memory, paging activity, and whether performance is affected rather than relying on a percentage alone.

## Disk space and activity

Low free space can limit updates and temporary files. Disk activity can also rise during updates, file copies, or antivirus scans. Distinguish storage capacity from moment-to-moment disk activity.

## Temperature and GPU readings

Temperature depends on the workload, cooling design, and sensor. Compare readings with the device manufacturer's guidance. If temperatures remain unusually high, check airflow and fan operation; avoid opening hardware unless you know how to do so safely.

## A useful troubleshooting routine

1. Note the symptom and when it occurs.
2. Capture readings during the slowdown and while idle.
3. Check the process list for a likely cause.
4. Change one thing at a time and compare.
5. Seek qualified help if the device shows shutdowns, burning smells, or other hardware warning signs.

Metrics are diagnostic clues, not a definitive diagnosis.
